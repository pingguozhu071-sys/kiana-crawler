# tests/assets/

测试用的样例资产。分三类：

| 类别 | 文件 | 用途 |
|---|---|---|
| 站点真实样本 | `*_sample.html`（知乎 / 微博 / 豆瓣 / 凤凰 / 搜狐 / 头条 / 少数派 / 韩文站等） | 规则层的离线回归——`rules/sites/` 下每条规则按约定需配一份真实样本，清单由发版门禁校验 |
| 平台数据样本 | `captcha_samples/`、`abogus_vectors.json` | 验证码形态样本；a_bogus 签名的固定向量（逐字节回归） |
| 图片样图 | `sample_anime_1.png`、`sample_anime_2.jpg` | 底图/壁纸管线的测试输入（`tools/v9_smoke.py` 会用到其中一张） |

**关于图片样图**：它们**不是本工程的原创作品**，来自作者个人收藏，**仅作测试输入**，
不参与任何功能逻辑。来源声明见 [`docs/ASSET-PROVENANCE.md`](../../docs/ASSET-PROVENANCE.md)。

**关于站点样本**：这些是从公开页面抓下来的静态快照，用于离线测试（测试套件不联网）。
样本中的用户昵称、正文等属于公开内容；其中出现的**联系方式已做脱敏处理**。
